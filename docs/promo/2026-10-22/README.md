# 게시용 자료

- `nexon-openapi-post.md`: 넥슨 Open API 게시용 업데이트 소개
- `community-post.md`: 커뮤니티용 소개 글
- `*.txt`: 제목·본문을 복사하기 위한 일반 텍스트
- `screenshots/`: 글에 첨부할 실제 서비스 화면
- `preview.html`: 이미지와 본문을 함께 확인하는 미리보기
- `fcoach-update-kit.zip`: 글·패치노트·스크린샷을 묶은 파일

게시판에서 이미지가 자동으로 붙지 않으면 `screenshots`의 사진을 본문 순서대로 첨부하세요. Markdown의 `![설명](경로)` 부분은 게시판 이미지로 대체하면 됩니다. `.txt`에도 사진 삽입 위치와 파일명이 적혀 있습니다.

이미지 순서와 설명:

1. `01-player-analysis-pc.png` — 포메이션에서 선수 선택, 해당 시즌·강화·자리의 경기 기록
2. `02-player-settings.png` — 선수의 기본·획득 특성과 훈련코치 아이콘
3. `03-team-passing.png` — 팀 패스 종류별 성공률·사용 비중 분석
4. `04-before-after.png` — 사용자가 고른 개선 전 10경기 / 후 8경기의 관측값 비교
5. `05-mobile-formation.png` — 모바일 포메이션과 선수 선택
6. `06-mobile-shot.png` — 모바일 슈팅 선택과 선수·시간 정보

게시글은 초안으로만 준비하며 실제 커뮤니티·넥슨 게시판에는 전송하지 않습니다. 데이터 출처와 비공식 서비스 안내는 본문에 포함했습니다.
